# 🎬 AnimeBox PRO — Ultimate Anime Streaming Experience

AnimeBox PRO is a modern, high-speed, cinema-grade Anime Streaming web application with multi-language support (Bengali & English), multi-server HD streaming, custom subtitle engine, and theater mode.

## ✨ Features
- 🚀 **5-Tier High-Speed Streaming Engine**: Powered by Consumet, HiAnime, GogoAnime, and Multi-Dub CDNs.
- 🎙️ **Dual Audio & Dubs**: Japanese Original, English Dub, Hindi Dub, and Bengali support.
- 🎭 **Cinema Theater Mode & Ambient Glow**: Immersive cinema watch mode with keyboard shortcuts (`T`, `F`, `N`, `P`).
- ⚡ **TanStack React Query**: Instant navigation and intelligent client-side caching.
- 📱 **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.

## 🛠️ Tech Stack
- React 18
- Vite
- Framer Motion
- Lucide Icons
- TanStack React Query
- Vanilla CSS Design System

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
